# 育成リソースノート

Pokémon Sleepのアメ・ゆめのかけらを記録・集計する、個人制作の非公式ツールです。公式運営・関係各社とは関係ありません。

[新デザイン専用TEST版を開く](https://mokuhibi.github.io/resource-journal-redesign-test/)

## 出発点：Ver.2.0.1

1. 編成でポケモンを登録し、チームに設定します。
2. 記録で日時・フィールドを確認して、アメやスキル・睡眠リサーチなどを記録します。
3. アメ・ゆめのかけらで集計し、履歴から訂正・削除できます。
4. 設定 → バックアップでCSVバックアップ・復元ができます。

記録は利用中の端末・ブラウザのIndexedDBに保存されます。ログインや端末間の自動同期はありません。サイトデータの削除やプライベート閲覧に注意し、定期的にCSVバックアップを行ってください。復元は現在のデータを置き換えるため、必要なデータは先にバックアップしてください。

新デザイン専用TEST版は、既存TEST版と同じドメインですが、異なる保存キーとIndexedDB名を使用します。本番版・既存TEST版の記録を自動では読み込みません。公開先をまたぐ移行にはCSVを使用してください。

出典・ライセンス・お問い合わせは、アプリの設定 → このアプリについてで確認できます。同梱コード・アイコン等の通知は [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) に保持しています。
